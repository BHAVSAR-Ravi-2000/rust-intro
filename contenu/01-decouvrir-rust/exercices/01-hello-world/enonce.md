Bienvenue ! Voici comment marche la plateforme :

- **Exécuter** : compile ton code et lance la fonction `main`. Tu vois ce qu'elle affiche.
- **Vérifier** (ou `Ctrl + Entrée`) : contrôle si l'exercice est réussi.
- Ton code est enregistré tout seul.

Premier exercice : modifie le programme pour qu'il affiche **exactement** :

```text
Hello, world!
```
