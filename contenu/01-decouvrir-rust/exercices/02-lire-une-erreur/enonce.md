Ce programme ne compile pas à cause d'une faute de frappe.

Clique sur **Vérifier**, lis le message d'erreur et corrige le code.

> [!tip] Lire jusqu'au `help:`
> Un message d'erreur Rust se lit en trois parties :
> - `error[E0425]` : le code de l'erreur et son résumé ;
> - `--> main.rs:6:20` : le fichier, la ligne et la colonne ;
> - `help:` : très souvent, la correction exacte à faire.
