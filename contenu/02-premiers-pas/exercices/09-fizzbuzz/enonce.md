Règles de FizzBuzz pour un nombre `n` :

- multiple de 3 et de 5 : `"FizzBuzz"` ;
- multiple de 3 seulement : `"Fizz"` ;
- multiple de 5 seulement : `"Buzz"` ;
- sinon : le nombre lui-même, en texte (`"7"`).
