# Rust Entraînement

Cours, quiz et exercices pour apprendre les fondamentaux de Rust, corrigés automatiquement.

## Il faut

- [Node.js](https://nodejs.org)
- [Rust](https://rustup.rs)

## Lancer

```bash
git clone https://github.com/toto-elgringo/rust-entrainement.git
cd rust-entrainement
npm start
```

Le site s'ouvre sur http://localhost:3000. Ta progression reste sur ton ordi.
